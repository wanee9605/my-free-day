# 연차 최적화 캘린더

달력에서 **연차를 직접 놓아 가며** 가장 긴 연휴를 만드는 도구입니다. 한 칸 더 쓰면 며칠이 늘어나는지 바로 보여 주고,
`추천으로 채우기` 를 누르면 최적 배분을 한 번에 깔아 줍니다.
공휴일 데이터는 정적 JSON, 계산은 전부 브라우저에서 처리하며 DB·로그인이 없습니다.

- 스택: Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · `next/og` · Vitest
- 대상 연도: 2026 · 2027 · 2028 (구조는 연도 무관, `lib/holidays/{year}.json` 추가로 확장)

## 실행

```bash
npm install
npm run dev          # http://localhost:3000
npm test             # 골든 테스트 (tests/optimize.test.ts)
npm run build && npm start

# UI 점검 (서버가 떠 있는 상태에서 실행, Microsoft Edge 사용)
npm run ui:check     # 뷰포트별 스크린샷 + 가로 넘침·터치 타깃·콘솔 오류 진단
npm run ui:interact  # 카드 연차 조정, 자동 복귀, 달력 필터, URL 동기화 동작 확인
```

`ui:check` 는 스크린샷을 `C:\Users\Public\shots` 에 저장합니다. 두 스크립트 모두 개발용이며 배포 산출물에는 포함되지 않습니다.

## 디자인 시스템

`design/v4-editor.dc.html` (Claude Design) 을 구현 기준으로 삼았습니다. 토큰은 `app/globals.css` 한 곳에 있습니다.

- **팔레트** — 웜 그레이 바탕(`canvas` #F1F1EF)에 딥 그린 액센트(`acc` #1F6F5C) 하나. 일요일·공휴일은 `sun`, 토요일은 `sat` 로만 색을 더 씁니다. 도구처럼 조밀하게 보는 화면이라 색 대비보다 **선과 밀도**로 위계를 만듭니다.
- **다크 모드** — 원시 변수(`--dc-*`)를 `:root` / `:root[data-theme="dark"]` 에서 갈아끼우고, Tailwind 유틸리티는 `@theme inline` 으로 그 변수를 가리키기만 합니다. CSS 변수 치환이 늦게 일어나므로 클래스는 그대로 두고 테마만 바뀝니다. 첫 페인트 전에 `layout.tsx` 의 인라인 스크립트가 저장값(없으면 OS 설정)으로 `data-theme` 을 확정해 흰 화면 깜빡임을 막습니다.
- **타이포** — Pretendard 하나, 12~13px 본문에 `tabular-nums` 고정폭 숫자. 숫자가 바뀔 때 칸이 흔들리지 않습니다.
- 공유 이미지(`app/api/og/route.tsx`)도 같은 라이트 팔레트 값을 상수로 복제해 씁니다. 토큰을 바꾸면 이쪽도 함께 맞춰 주세요.

## UX 설계

- **달력 직접 배치** — 평일을 누르면 연차가 놓이고 다시 누르면 빠집니다. 한도를 넘기면 더 놓이지 않습니다. 연차가 들어간 연속 휴일 구간은 달력에 **하나의 띠**로 이어져, 며칠이 붙었는지가 색이 아니라 형태로 보입니다.
- **지금 한 칸 더 쓰면** — 남은 날 하나하나를 실제로 넣어 보고 휴식이 가장 많이 느는 순으로 3개를 제안합니다. 마우스를 올리면 달력의 그 칸에 점선 힌트가 뜹니다.
- **만들어진 연휴** — 배치 결과가 구간 목록으로 실시간 갱신됩니다. `×4.5` 는 연차 1일이 만들어낸 휴일 수입니다. 목록에 마우스를 올리면 달력의 해당 구간이 함께 강조됩니다.
- **추천으로 채우기** — 배낭 DP(`optimize.ts`)가 고른 배분을 한 번에 깔아 줍니다. 우선순위·한 연휴 최대 연차·제외 기간은 **이때 적용되는 규칙**이고, 깐 뒤에는 손으로 고치면 됩니다.
- **접이식 설정** — 연도·근무 형태, 추천 규칙·제외 기간, 연차 개수 계산, 공유·내보내기를 좌측 패널 아래 접어 두었습니다. 닫힌 상태에서도 요약(`2027년 · 주 5일`)이 보여 지금 무슨 설정인지 알 수 있습니다.
- **연차 개수 계산** — 입사일만 넣으면 근로기준법 60조 기준으로 한도를 채워 줍니다. **입사일은 URL에 넣지 않습니다** — 개인 정보가 공유 링크에 실리지 않게 하기 위해서입니다.
- **근무 형태** — 주 5일 / 주 6일 / 교대근무(근무 N일·휴무 M일·주기 기준일). 쉬는 날을 무엇으로 볼지만 바뀌고 이후 계산은 그대로라, 교대근무자도 같은 화면을 씁니다.
- **캘린더 내보내기** — `.ics` 로 내려받아 구글·애플·아웃룩에 넣습니다. 연휴 구간(바쁨 아님)과 연차 사용일(바쁨)을 각각 일정으로 넣습니다.
- **접근성** — 달력 칸은 `button` + `aria-pressed` 라 키보드로 배치할 수 있고, 색에 더해 `연차`·공휴일명 텍스트를 함께 답니다.

## 알고리즘 요약

1. **날짜 배열** — 대상 연도 전체 + 앞뒤 10일 패딩(성탄절→다음 해 신정처럼 해를 넘기는 연휴 반영). 패딩 날짜는 연차 대상이 아님. 쉬는 날은 `isOffDuty`(근무 형태) + 공휴일로 정해지므로, 교대근무는 `isOffDuty` 만 갈아 끼우면 2단계부터는 동일하게 돌아감.
2. **클러스터** — 연속 휴일 블록을 평일 간격 `gap ≤ 5`이면 병합하되, **둘 중 한쪽에 공휴일이 있을 때만** 병합. 일반 주말끼리의 간격도 정확히 5이므로 이 조건이 없으면 1년 전체가 하나로 합쳐집니다. 공휴일이 없는 클러스터는 제외 → 2026년 8개, 2027·2028년 각 10개.
3. **가성비 곡선** — 최대 연속 휴일은 항상 하나의 연속 구간이고 그 안의 평일을 모두 연차로 채워야 하므로, 구간 전수 조사(O(L²))가 부분집합 전수 탐색(2^m)과 같은 결과를 냅니다. 평일 개수 상한(12개) 없이 정확히 계산됩니다. 곡선은 단조 증가하도록 후처리하며 `usedLeave ≤ k`의 차이가 "써도 늘지 않는 연차"입니다.
4. **배낭 DP** — `dp[i][n] = max_k dp[i-1][n-k] + curve_i[k].gain`, 역추적으로 클러스터별 배정 복원. 동점이면 적은 연차를 택해 잔여 연차를 미사용으로 표시.
5. **모드** — `longestStreak`(기본): 연차 N개 이하로 가능한 최장 연휴 1건을 먼저 확정(동점이면 더 이른 날짜), 잔여 연차만 DP. `totalGain`: 전체 DP.

## 공휴일 데이터 갱신

```bash
cp .env.example .env.local   # DATA_GO_KR_SERVICE_KEY 입력
npm run fetch:holidays -- --year=2028
# → lib/holidays/2028.json 생성 후 lib/holidays/index.ts 의 HOLIDAY_DATA 에 등록
```

임시공휴일(선거일 등)은 API 반영이 늦을 수 있습니다. JSON을 직접 고치면 재생성할 때 되돌아가므로, 표기 보정은 스크립트의 `DISPLAY_NAME` 에 두세요(예: API 의 `1월1일` → `신정`, `기독탄신일` → `성탄절`). 화면 하단에 데이터 기준일이 표시됩니다.

2026년 법 개정으로 **노동절(5/1)이 공휴일이 되고 제헌절(7/17)이 18년 만에 부활**했으며, 둘 다 대체공휴일 대상입니다. 2027년은 두 날이 모두 토요일이라 5/3·7/19 대체공휴일이 붙습니다. 이 두 공휴일이 빠지면 5월·7월 추천이 통째로 달라지므로 `tests/optimize.test.ts` 에서 연도마다 존재를 검사합니다.

진행 중인 연도(현재 2026)를 선택하면 이미 지난 날짜는 연차 후보에서 제외됩니다(`buildDays` 의 `notBefore`). 기준일은 `todayInSeoul()` 로 시간대를 한국에 고정하고, 정적 HTML 에는 연도 전체가 담기도록 브라우저 마운트 후에만 적용합니다.

## 공유 링크·이미지

- 입력 상태는 `?leave=6&sel=8d8h&mode=longest&blackout=2027-09-01~2027-09-30&work=4-2:2027-01-01&maxrun=3` 형태로 URL에 반영되어 링크만으로 복원됩니다. `sel` 은 **배치한 날짜**로, 연중 며칠째인지를 36진수 두 자리로 적어 25일치가 50자에 들어갑니다. `work` 는 주 5일이면 생략하고, 주 6일은 `week6`, 교대근무는 `근무-휴무:기준일` 로 씁니다. 입사일은 여기 담기지 않습니다.
- `/api/og?year=2027&leave=2` 가 같은 파라미터로 결과를 재계산해 1080×1350 PNG를 생성합니다. 한글 폰트는 Google Fonts(Noto Sans KR)를 렌더 텍스트만 서브셋으로 받아 사용하며, 네트워크가 막힌 환경에서는 기본 폰트로 폴백됩니다.
- 공유 버튼이 복사하는 링크는 쿼리를 단 `/` 이므로, `app/page.tsx` 의 `generateMetadata` 가 그 쿼리로 결과를 재계산해 제목·설명·OG 이미지에 반영합니다. 쿼리가 없으면 사이트 기본 문구를 유지합니다. 이 때문에 `/` 는 동적 렌더링이고 `/2027` 은 SSG 입니다.
- `og:url` 에는 쿼리를 포함한 URL 이, `canonical` 에는 `/` 가 들어갑니다. 메신저 카드를 눌렀을 때 공유한 상태로 돌아오면서도 쿼리별 URL 이 따로 색인되지 않게 하기 위해서입니다.
- 배포 시 `NEXT_PUBLIC_SITE_URL` 을 실제 도메인으로 설정하면 메타 태그·sitemap 에 반영됩니다. 현재 프로덕션은 https://my-free-day.vercel.app 이며, `main` 에 푸시하면 Vercel 이 자동 배포합니다.

## 명세서 대비 변경점

| 항목 | 명세 | 구현 | 사유 |
|---|---|---|---|
| 클러스터 병합 | `gap ≤ 5` | `gap ≤ 5` **그리고** 한쪽에 공휴일 | 주말 간격이 5라 조건만으로는 1년이 한 클러스터가 됨 |
| 곡선 계산 | 부분집합 2^m 전수 + m>12 상한 | 구간 전수 O(L²) | 결과 동일, 상한 불필요 |
| 추석 곡선 cost 1 | 5일 | **6일** (9/11~9/16) | 명세 표의 계산 오류 |
| 공유 이미지 런타임 | `@vercel/og` Edge | `next/og` Node | Next 16에서 Edge Runtime deprecated |
| 클러스터 수 | 10~15개 | 2027년 10개 | 노동절·어린이날·부처님오신날, 개천절·한글날이 각각 한 클러스터로 병합됨 |
| 화면 | 연차 개수 입력 → 추천 카드 | 달력 직접 배치 + `추천으로 채우기` | `design/v4-editor.dc.html` 을 구현 기준으로 삼음. DP 는 추천을 깔 때만 돌고, 이후는 손으로 고침 |
| 2027 공휴일 | 명세·`design/core.js` 목록 | 공공데이터포털 API 생성본 | 둘 다 설날이 하루 밀려 있고 노동절·제헌절이 빠져 있음. **`design/core.js` 를 참고용 외의 용도로 쓰지 말 것** |
